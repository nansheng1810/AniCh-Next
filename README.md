## ⚡ 超分辨率

播放器支持**实时超分辨率**：基于 GPU 硬件解码与 4K 渲染，针对低分辨率片源有效减少模糊与锯齿，在不明显增加性能负担的前提下获得更清晰的画面。所有着色器均可在播放页按需切换。

## 🛠️ 相对上游的修改

<details open>
<summary><b>🎨 界面布局</b></summary>

- 桌面播放页改为双栏布局：左侧视频舞台 + 右侧 320px 侧栏（追番 / 返回详情、简介与评论切换、选集网格、当前集高亮、返回主界面浮层、底部控制条）。
- 新增桌面端自绘标题栏的最小化 / 最大化 / 关闭按钮，并补充悬停主色反馈。
- 新增「隐藏侧栏」按钮，返回主界面按钮不再被视频层遮挡。
- 删除图片页、我的页、番剧库、番剧详情页中重复的关闭按钮。
- 修复从播放页返回番剧详情时出现灰块或空白的问题，并补充加载动画与错误兜底。

</details>

<details open>
<summary><b>🚀 1.3.0 增强（Phase 2 & 3）</b></summary>

- 离线缓存升级为并发队列：1–6 并发、超出自动排队；下载页支持批量选择删除、全部暂停 / 继续与清空已完成。
- 新增缓存目录设置与缓存完成系统通知；番剧详情页支持「批量缓存」整季（自动跳过已缓存与 m3u8 线路）。
- 新增本地弹幕：支持 JSON / XML（哔哩哔哩、ACFun 格式）导入并自动合并去重，可将当前全部来源弹幕导出为 JSON / XML。
- 新增弹幕搜索：跨本站、哔哩哔哩、港澳台、腾讯视频与本地弹幕搜索关键词，点击结果跳转到对应时间。
- 新增多线路测速：测试每条线路的延迟与下载速度，可手动或自动切换到最快线路。
- 新增智能片头：记录用户重复快进的落点，连续两次接近时学习为片头结束点并自动跳过。
- 新增 DLNA 投屏：SSDP 搜索局域网 MediaRenderer 设备，推送当前线路地址或本地缓存（内置局域网 HTTP 文件服务）。

</details>

<details open>
<summary><b>▶️ 播放增强（1.2.0）</b></summary>

- 新增外挂字幕：加载本地 SRT / ASS / SSA / VTT，支持字号、描边、加粗、底部距离与字幕延迟实时调节，换集 / 换线路自动重新挂载。
- 新增片头片尾标记：按番剧记录片头结束与片尾开始，自动跳过片头、片尾直接衔接下一集。
- 新增播放行为设置：进入播放页自动全屏、自动连播、长按画面临时倍速（2.0–4.0X）。
- 新增睡眠定时：15 / 30 / 45 / 60 / 90 分钟后暂停，或本集播完后暂停。
- 新增 A-B 循环：在播放页任意设置 A / B 点循环播放（增强功能）。
- 新增观看统计：累计 / 本周观看时长、已看完集数、观看过的剧集与追番数量，本地保存并可一键清空（增强功能）。
- 新增播放器日志面板：在播放设置内查看、复制、清空最近的播放日志。
- 手机端与桌面端播放设置合并为同一组件，新增设置不再需要两处重复维护。

</details>

<details>
<summary><b>🎮 播放与交互</b></summary>

- 修复进入全屏后方向键快进 / 快退失效的问题。
- 修复实际播放集数变化后，侧栏标题与选集高亮仍停留在旧集的问题。
- 优化播放错误处理：播放失败弹窗后返回详情页可自动恢复。

</details>

<details>
<summary><b>💬 评论</b></summary>

- 新增评论总数显示（「全部评论 (N)」）。
- 新增评论分页加载（加载更多评论 / 没有更多评论了）。
- 新增侧栏评论发布框，支持发布、回复、点赞与加载失败重试。
- 适配新版评论接口：正文使用 `text` 字段提交，发布成功后立即插入列表并补全缺省字段。

</details>

<details>
<summary><b>🖥️ 桌面与稳定性</b></summary>

- 新增后台常驻与托盘右键菜单（显示主界面 / 退出）。
- 网络层统一 UA 与 `_` 鉴权头，增加请求超时与 GET 自动重试。
- 新增 GitHub Actions CI（`flutter analyze` + `flutter test`）。
- 补充 `docs/wiki` 项目文档。

</details>

## 📦 从源码构建

环境要求：Flutter 3.22.3（Dart 3.4.4+），详见 [构建运行与开发指南](docs/wiki/09-构建运行与开发指南.md)。

```bash
flutter pub get
flutter analyze
flutter test

# Windows
flutter build windows --release
```

本仓库仅维护 Windows 构建；其他平台请前往原项目仓库。

### 🧰 打包 Windows 安装包

仓库内提供 Inno Setup 脚本 [installer/AniCh.iss](installer/AniCh.iss)，构建 Release 后执行：

```bash
ISCC.exe installer\AniCh.iss
```

输出 `dist\AniCh-1.3.0-Setup.exe`。如构建目录不在默认位置，可传入 `/DBuildDir="..."`。
